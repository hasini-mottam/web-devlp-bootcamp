# web-devp-project
A beginner-friendly web application built using HTML, CSS, JavaScript, Node.js and Express.js.

## Features

- User card with toggle functionality
- Random user feature
- REST API for users
- GET, POST, PUT and DELETE operations
- LeetCode stats page
- Codeforces stats page
- GitPulse page
- Ask Gemini page
- Frontend and backend integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Thunder Client

## How to Run

1. Install Node.js
2. Clone this repository
3. Open the project folder in the terminal
4. Run:

npm install
node server.js

5. Open http://localhost:4040 in your browser
